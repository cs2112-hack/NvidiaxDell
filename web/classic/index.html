Five agents are ready to sue this company.

They read your documents and propose claims against you. Each claim is executed against your own encoded policy, and only the ones that land reach the queue. The rest die without anyone having to read them.

Each sweep runs four stages, in order

    Attacks

    • Died at the executor
    • Nothing usable to judge
    • Landed on a hole already queued
    • Landed and queued
    • Not yet run

    The fleet

    Each agent reads the clauses and one rule’s machine interface. None is shown the file that defines a bad outcome: an agent that knew what counts would reproduce it, and what survived would mean nothing.

    Draft a new document

    Describe the document you need. An agent drafts it from the closest precedent in the corpus, then the draft has to pass the Catala gates and a screen of three reviewers before a PDF is issued. A draft that fails any of them is marked not issued, and is never presented as a document.

    Leave it blank and the document says TO BE CONFIRMED. The date decides which facts a rule governs, so it is never guessed.

    Run options

    Past drafts

    Ask what the documents require.

    A question about a rule is answered by running that rule. A question about wording is answered by quoting the clause. Each part of the answer says which it is, and the two are never blended.

    Rules Ross can run

    Each rule encodes named clauses and computes a result from facts you give it. Where a clause turns on a judgement the documents don’t define, that judgement is a field a person fills in. The rule never decides it.

    The corpus

    Every document as ingested. The column beside each is divided by how much of it runs as a rule, how much is a rule gated on a judgement, and how much can only be quoted. Open a document to reach any clause.

    Documents waiting for a decision

    An incoming document becomes a proposal, never a merge. Every blocking conflict needs a person to record how it was resolved, and who resolved it, before the document joins the corpus.

    What has been checked

    Every way this system has been shown to be wrong is kept as a test and run again. Defects in the source documents are listed separately, because those need amending rather than fixing.
