        For administrators: how documents reach the watch

        The watch reads two collections in the lks MongoDB database. chunks is the index of the corpus: a document there is watched once it has been merged and re-indexed. documents is the intake: any system may add a document to it, and it is split into clauses automatically.

        db.documents.insertOne({ "text": "…the document…", "doc_id": "TRAVEL-2026", "title": "Travel Policy 2026" })

        Only text is required. A document counts as new when it has not been seen, and as changed when its clauses change, so re-indexing the same corpus on a restart checks nothing again. The documents already in MongoDB the first time the watch runs are recorded as the baseline and are not checked unless someone asks.

        The watch runs inside the web server. LKS_DOC_WATCH=0 turns it off; LKS_WATCH_INTERVAL sets how many seconds it waits between looks. From a terminal, lks watch status and lks watch results show the same information as this page.
